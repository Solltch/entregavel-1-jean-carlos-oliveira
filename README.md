# entregavel-1-jean-carlos-oliveira
Verificador de Bateria
Programa em Python que verifica se a bateria disponível em um robô é suficiente para concluir uma missão.

O programa solicita:

Bateria atual (%)
Duração da missão (minutos)
Consumo de bateria por minuto (%)

Depois, calcula o consumo total e informa se a missão pode ser concluída, mostrando a bateria restante ou quanto de bateria faltaria.

Execução
python main.py
Requisitos
Python 3.x
